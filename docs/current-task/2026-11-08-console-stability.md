# 控制台布局稳定性

2026-11-08，`feat/visualization`。范围是节点位置、轮询快照、Timeline 渲染边界和选中状态；后端接口与协议不变。

## 固定骨架与增量数据

- 固定：侧栏和页签、筛选栏、工作负载面板位置与高度、拓扑五/六个固定槽位、泳道行高与总高度、事件表列宽与容器高度、写追踪面板。
- 增量：指标数字、节点角色样式、RPC 弧线、复制组刻度与事件点、事件行、追踪四步事实、集群采样。更新只影响对应局部。
- 拓扑节点按成员清单固定槽位；Leader 变化只改变角色样式和关系线，不移动节点。轮询失败保留最后一次成功快照，只显示离线警告。
- Timeline 的 1 秒时钟移入 `Swimlane`，只有泳道内部重绘；筛选、表格和追踪面板不再每秒重排。选中事件在首次出现后保持，除非被筛选掉或缓存淘汰。
- 事件表使用固定列宽和事件标签省略；表格与追踪面板 memo 化；追踪说明区预留高度；工作负载数字使用等宽数字、最近结果不换行。

## 验证

- `pnpm test` 18 个文件 102 项通过；拓扑测试改为验证 Leader 切换时槽位不变。
- `pnpm typecheck`、`pnpm build:web` 通过。
- 浏览器：拓扑节点间隔 4 秒两次采样位置完全一致；Timeline 选中 AppendEntries 后，工作负载面板、泳道、追踪面板、事件表位置和五列宽度在 4 秒内完全一致；事件表 `top 1371 / height 416` 两次一致；离线模拟时 5 个节点保留、显示离线警告，恢复后自动清除；暂停跟随后泳道时间轴 2 秒内不变。
- 未做整页性能剖析；本轮以布局几何、选中状态和 DOM 行为作为验收。

## 壳层、控件与聚焦稳定性（续）

- Raft 集群、实时事件、实验回放共享同一个 `<main>` 和一组 `RaftTabs`，切换子页只替换内部内容；移除 `main` 的进入动画，`overview-banner` 统一最小高度，避免整页重新挂载造成的闪烁和重排。
- 全部原生 `<select>` 替换为 `web/src/select.tsx`：触发器与下拉浮层使用设计 token，自定义箭头、选中勾选、键盘导航、外部点击关闭；菜单绝对定位，不改变页面几何。箭头保留 12px 内边距，不再贴边。
- 泳道节点标签左内缩 10px，避免节点名贴住面板边框。
- 写追踪改为用户点击事件行或复制组后才出现；默认选中最新事件时不自动展开。没有复制证据时不渲染“按节点观测”表，避免未观测写产生大块空白。
- `html` 使用 `scrollbar-gutter: stable`，不支持时回退 `overflow-y: scroll`，固定设置页/抽屉切换时页面滚动条占位；Raft 集群页签点击回到页面顶部，不因锚点滚动把壳层推走。
