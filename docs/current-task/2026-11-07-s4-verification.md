# S4 · 一致性验证与后端冻结

基线为 `5c3a449`。依次实现 S4A 合法顺序搜索、S4B 事务依赖图、S4C 值班不变量、S4D 证据回放及系统对比。验证器只读取历史。回放将原始 R03 和 T02 文件的路径、摘要与新判定写入 V01–V03。

## 判定口径

- S4A 按键检查 get、put、delete。从调用方声明的初值出发，成功调用必须进入合法顺序。确定拒绝的调用无状态效果。未知或未返回的写允许发生一次或省略，客户端超时只表明观测终止，未知写仍可在超时后生效。未知读无状态效果，可省略。已成功返回且早于另一调用的操作必须排在后者之前。返回每键可行顺序或阻塞读写与实时约束，搜索预算或必要输入缺失时返回 `INCONCLUSIVE`。
- S4B 使用从空库开始的完整事务提交序列。每键以最终写生成已提交版本，墓碑保留身份。相邻版本形成 WW，实际观察版本的创建者到读者形成 WR，读者到观察版本的直接后继形成 RW。无版本的读以初始缺失作为链首。私有读与自环排除。缺失或矛盾的版本证据返回 `INCONCLUSIVE`。
- S4C 单独按事务提交原子地更新值班状态，在指定生效区间逐提交检查至少一人值班。输出最早违规的提交、当前版本、相关写和读证据。
- S4D 对 R03 的唯一实验键使用初始空值，对 T02 分别验收无锁与锁修复时段。V02 另附合成的 WW/WR/RW 三边环。实验通过表示检查器得出预期结果，历史本身可判为 FAIL。后端冻结后，工作转为注释、文档、可视化探针和前端所需数据结构。

## 复杂度与能力边界

- 每键有 n 个参与搜索的调用，搜索状态由已放置操作集合和寄存器值组成。记实际搜索状态数为 S，预计算实时关系及回溯约为 O(n² + nS) 时间和 O(n² + S) 空间，按固定大小的键和值计算。S 的最坏上界是 O((n + 1)·2ⁿ)。默认最多每键 64 个参与操作、全历史 100,000 个搜索状态、搜索时间 1 秒，达到搜索边界返回 `INCONCLUSIVE`。输入须提供已知初值与同一驱动时钟。时间戳相等按没有已知先后处理，适用范围为单键操作组成的有限历史。反例给出一个搜索死端及实时关系，最小化留作扩展。 [Herlihy 与 Wing 原论文](https://www.cs.cmu.edu/~wing/publications/HerlihyWing90.pdf)
- 依赖图中 T 为提交事务数，A 为读写访问数，R 为读数，W 为版本数，E 为依赖边数。索引、查读版本和找环共 O(T log T + A + R log(W + 1) + E) 时间。图只判定有序点读写版本下的序列化环，覆盖范围外包括谓词、幻读、未提交读的完整异常分类及事务级真实时间。 [Adya 等人的依赖图定义](https://people.eecs.berkeley.edu/~adj/cs262/papers/icde00.pdf)
- 值班检查复用版本索引并逐提交更新键状态。K 个值班键、C 个受检提交增加 O(KC) 时间。检查生效区间由调用方声明，覆盖观察到的提交状态，布尔真表示值班，墓碑或已知缺失表示不值班。
- 离线回放报告只覆盖指定 Run 的记录。R03 验证了一个合法线性化顺序，T02 的无锁环是在合法 SI 执行中观察到的非串行化结果。原始 R03 采集判定仍保留为 `INCONCLUSIVE`，独立的 V01 记录实际回放结论。
