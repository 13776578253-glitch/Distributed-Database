# 审计收束

## 事务键编码与旧库升级

事务服务接受任意非空 JavaScript 字符串作为键。旧版通过 SQLite TEXT 接收原始键，编码转换会把单独的代理码元替换成 U+FFFD。同一事务中不同键可能因此落入同一个提交分组。WAL 中的 JSON 记录仍保留原始键。

SQLite 以 JSON 字符串编码保存键，按编码分组，加载版本链时解码。旧库升级是启动时独立的 SQLite 事务。它根据原 `appliedLsn` 从完整 WAL 重建版本表，连同 `user_version` 一次提交。恢复阶段随后按原检查点与游标继续处理。迁移中断时 SQLite 回滚，下一次启动可重试。升级会重放旧库已物化的 WAL 前缀，耗时随前缀增长。需要回退到旧版时，使用升级前一同备份的 WAL 和 SQLite 文件。

定向验证覆盖新库、模拟旧版合并的库、历史查询、检查点中的待撤销事务和二次启动。旧库样本从 WAL 恢复了被合并的两个键，重复恢复只产生一条 CLR。
