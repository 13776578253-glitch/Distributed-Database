# 控制台设计系统重构

2026-11-07，`feat/visualization`。范围是控制台视觉层，后端契约、页面结构和数据流不变。

## 范围

- 以 SnowLuma 的冷白、天空蓝、细等高线和玻璃卡片语言为参考，重写 `web/src/style.css`：语义色、字号、间距、圆角、阴影和动效统一为令牌；页面骨架、面板、按钮、字段、表格、徽章、拓扑和泳道全部使用同一套令牌。
- 新增 `web/src/texture.tsx`，固定渲染细等高线背景和顶部径向光晕；`web/src/main.tsx` 挂载该层。背景不参与交互，使用 `aria-hidden`。
- 浅色为冷白画布、纯白表面和天空蓝焦点；深色为深蓝灰表面与浅蓝焦点。成功、警告和危险分别使用绿、琥珀和玫红语义色。
- 修复泳道在故障拆分后“未知”段继续携带原事件 ID 的问题，避免选中状态扩展到大片未知区间。
- 页面结构、路由、数据请求和既有交互保持不变。
