# 侧栏收束与 Raft 页签

2026-11-08，`feat/visualization`。范围是控制台导航信息架构，页面内容和后端接口不变。

## 范围

- 侧栏从 8 项收束为 4 项：Raft、事务、一致性验证、设置。
- 移除总览、节点拓扑、节点详情三个页内锚点；集群页仍包含这些区块，但不再占用侧栏。
- 实时事件与实验回放并入 Raft 入口，分别通过 `集群`、`实时事件`、`实验回放` 三个页签进入。`#/timeline` 和 `#/runs` 路由保留，旧链接和验证来源跳转继续可用。
- 新增 `web/src/raft-tabs.tsx`；`navigation.tsx` 用匹配函数让 Raft 项在三个子视图上都保持选中。顶栏统一显示 Raft 上下文，页签显示当前子视图。
- 事务、一致性验证、设置页面内容不变；侧栏标签缩短为事务、一致性验证、设置。
