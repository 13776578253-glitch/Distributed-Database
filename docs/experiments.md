# 实验清单

正式实验的命令和结果随实现补充。每次运行将命令、UTC 时间、Git SHA、参数、事件、原始日志和判定写入 `evidence/<ID>/<runId>/`。

## 方向一 · Raft KV

| ID | 动作 | 判定 |
| --- | --- | --- |
| R01 | 强制杀死 Leader，再启动该节点 | 在限定时间内重新选举，确认过的写入仍可线性一致地读到 |
| R02 | 双向阻断五节点 RPC，形成 3–2 分区，再恢复 | 多数派提交，少数派无法确认写入，恢复后已提交前缀一致并收敛 |
| R03 | 采集并发读写调用及返回 | 使用同一进程的单调时钟，S4 回放后给出线性一致性判定，另含负例 |

## 方向三 · MVCC/WAL

| ID | 动作 | 判定 |
| --- | --- | --- |
| T01 | 在提交前后、检查点和 Redo 中强制终止 | 恢复结果符合持久化 COMMIT 边界，无半提交，AS OF 可由日志核对 |
| T02 | 构造 SI 跨键写偏差，再执行显式加锁版本 | 原始运行打破值班约束，修复运行保持约束 |
| T03 | Undo 写入 CLR 后再次强制终止 | 再次恢复沿撤销链继续，终态与一次完整恢复一致 |

## 方向四 · 一致性验证

| ID | 输入 | 判定 |
| --- | --- | --- |
| V01 | 线性一致性正例和迷惑性负例 | 返回预期判定，给出反例依据 |
| V02 | 带读写版本证据的环 | 定位具体事务和 WW/WR/RW 边 |
| V03 | 业务约束破坏历史 | 给出违反约束的事务与观测证据 |
